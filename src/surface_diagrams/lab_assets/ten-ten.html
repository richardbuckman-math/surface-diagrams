Conventions and current limits

Read factor rows and braid from top to bottom. Drag downward applies (u,v) → (u v u⁻¹,u); drag upward applies (v,u) → (u,u⁻¹ v u). Each adjacent move is checked using exact Artin actions. Global conjugation replaces every factor f by g f g⁻¹, changing the whole product by conjugation; the saved global frame records g through undo and reload.

Supports use the library’s Arc/Loop surface renderer. Arcs and closed curves are recovered from exact boundary words. Both must pass an exact class check and the library route solver. These supports transcribe the supplied directions. “Up through k” crosses the gap immediately after point k from below to above; “down” crosses the other way. The six points run left to right; factors run top to bottom. Above and below in these drawings follow that source convention. Positive twists use the existing braid convention. Every edit is checked against this transcription’s exact disk product. The full sphere product is currently nontrivial; this is not yet a certified closed genus-two relation. The lantern option is for three marked points in a disk. Boundary-framed lantern and general daisy substitutions are not implemented.
