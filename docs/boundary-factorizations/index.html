What the counts mean

The target is one positive exterior-boundary twist, multiplied by the chosen power of every inner-boundary twist. A non-singleton block contributes one to each enclosed pair and one to each enclosed boundary. The orange singleton row gives the signed powers needed so that every column has the target total. Negative entries mean inverse boundary twists. If you require only positive twists and choose extra power 0, the full exterior twist by itself is the sole possible pattern.

Matching counts is a necessary condition in the abelianization. Supporting curves, factor order, and exact mapping-class equality remain to be found. The catalog does not label these patterns as verified factorizations. An eight-boundary surface has seven inner boundaries; choose “7 inner / 8 total” for that convention.
